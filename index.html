A LITTLE CONTEXT

看布局，也了解边界。

把网页放进另一块屏幕

粘贴 HTTP 或 HTTPS 地址，选择右上角的机型。自有与局域网项目默认框内显示，公网网页默认请求独立窗口。折叠屏可切换内外屏；切换屏幕、旋转和缩放会保留同一个框内页面。

宽高是参考值，可以校准

网页按标出的 CSS 宽高排版，外层缩放只调整展示大小。默认视口按厂商屏幕像素和参考缩放比 3 换算，并非厂商保证的浏览器可用尺寸；可用“自定义尺寸”校准。

同事怎么一起用

点击“分享预览”，复制局域网链接。若服务只在本机开放，请使用“局域网共享启动.cmd”重新启动。同事无需安装预览软件；只需浏览器和相同网络。收到链接不会获得你的登录状态或表单数据。

遇到灰屏或登录问题

部分网站禁止被其他网页嵌入，登录也可能受第三方 Cookie 限制。可使用“独立窗口打开”或地址栏的新标签页按钮。独立窗口的实际尺寸由浏览器决定。本工具不代理网页、不移除网站的安全设置。

这些仍然要看真机

鸿蒙与 iOS 内核、触摸手势、安全区、软键盘、麦克风、安装到桌面及折叠设备 API 都需要真机验收。
